# Enmity-Combat-Systems
A minecraft combat system framework heavily inspired by action rpg games such as Punishing: Gray Ravens, Wuthering Waves, dark souls, and more

# How to build
run gradlew build on this folder on your command prompt or terminal

# Dependencies
latest version of photon editor and ldlib

# Compatibilities
camera altering mods such as lock on and leawind's third person
